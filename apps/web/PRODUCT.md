# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

White-collar administrators and middle managers use the system on desktop computers.

## Product Purpose

The system manages quality and safety workflows across projects.

## Operating Context

Users work in a desktop administrative environment. They navigate project, quality, safety, task, settings, and master-data workflows.

## Capabilities and Constraints

- Desktop only.
- Preserve all current product functions, routes, content, workflows, and information architecture during the visual redesign.
- The application uses shared UI components from `@southneuhof/loom`.
- Framework source changes require separate approval.

## Product Principles

- Make routine administrative work clear and efficient.
- Keep project quality and safety information easy to scan.
- Preserve consistent interaction patterns across application and framework surfaces.
- Change visual presentation without changing product behavior.
