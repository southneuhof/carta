## Why this matters

The framework exposes many built-in input renderers but no stable unauthenticated
page to inspect their layout, loading, validation, and emitted values. A public
catalog catches visual regressions without login or seeded business data. A live
debug panel makes each control's effective form value inspectable while keeping
the card/form realistic.

## Steps

### Step 1: Inventory controls and fixtures

Create a typed fixture list with stable key, label, renderer, initial value,
props, and expected debug representation for all 31 registry keys. Include
options for select/radio/checkbox-group, tags, currency/number, date/range, and
safe local placeholders for file/image/canvas/editor. For lookup,
master-lookup, location, multi-location, table, dynamic-form, and file-manager,
use a documented local adapter/empty state while still showing the component.

**Verify:** fixture test enumerates exactly registry keys; missing/duplicate key
fails.

### Step 2: Build public page through `Form`

Create one responsive card containing heading, description, and actual framework
`Form` from the fixture schema. Use a grid; separators/composites span full
width. Submit stays local and records a snapshot; no network/API call.

**Verify:** route test mounts without auth, asserts representative labels,
local-only submit, and zero fetch calls.

### Step 3: Add live debug view

Render “Form data” card/panel showing reactive draft values, submitted snapshot,
and validation errors. Use safe JSON serialization for `File`, `Blob`, dates,
maps, and opaque/circular values; never use `v-html`.

**Verify:** test edits a text control, submits, and finds new value in debug
output while network mock remains untouched.

### Step 4: Make public and review visually

Register under `(public)`. Do not add authenticated menu unless a public
navigation affordance already exists. Check desktop/narrow viewport,
asynchronous loading/error states, labels, and no horizontal overflow.

**Verify:** web build/typecheck pass; fresh unauthenticated browser context opens
the direct URL.
